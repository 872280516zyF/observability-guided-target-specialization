# Submission release notes

This is the code snapshot prepared for peer review of the Nature Communications
manuscript.  The primary grouped observability, inverse prediction, matched
controls, forward consistency analysis and reported Supplementary analyses are
included. Publication-figure plotting and manuscript-layout scripts are excluded;
their numerical inputs are supplied in the separate Source Data archive.

The archive intentionally excludes model weights, cached tensors, training
logs, local manuscripts and third-party public datasets.  Reported grouped OOF
predictions and all numerical figure/table inputs are supplied in Source Data,
so every reported statistic can be checked without rerunning GPU training.

Before public deposition, replace `LICENSE_TO_SELECT.md`, complete
`CITATION.cff.template`, and add the final repository URL and DOI.
